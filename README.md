# 算法之旅 · ALGO QUEST

面向编程零基础的 Java、数据结构与算法学习网站。72 节基础课程、41 篇专题，支持推演、练习、笔记和免登录本机学习，无需 AI 服务。

[在线学习](https://zz238.github.io/algorithm-quest/)

## 快速开始

需要 Node.js 20.19+ 或 22.12+（建议使用受支持的 LTS 版本）。

```sh
npm ci
npm run dev
```

开发地址以终端为准。`npm run build` 生成生产版本，`npm run preview` 预览；可选离线版使用 `npm run build:offline`。

## 学习体验

- 知识图谱呈现课程和专题前置关系，节点可直接进入课程。
- 递归/链表逐行推演展示调用栈、局部变量、引用；对比栈/队列、BFS/DFS、归并/快排。
- 正确率与耗时驱动可关闭的难度推荐；错题按概念、边界和复杂度给出复习建议。
- 每章 Easy + Medium，另有时间/空间复杂度训练。
- 浅色、暗色或跟随系统；触屏只读高亮与手算，电脑可按需运行 Java。
- 游客无需 GitHub，可导出 JSON 或生成带临时口令的加密数据串迁移学习记录。
- 全文模糊搜索覆盖正文、代码注释和当前存档私人笔记。
