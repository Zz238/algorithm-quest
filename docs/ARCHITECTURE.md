# 技术架构与设计决策

Vue 3、Vite 和 hash 路由；课程、练习与推演均在前端运行。首页使用轻量索引，正文和学习工具按需加载。保留纸色文档风格，提供浅色、暗色和跟随系统主题。

## 课程与工具

`course.js` 组合课程，`course-index.json` 是生成的轻量目录，`course-route.js` 校验深链接。知识图谱复用 72 节课程与 41 篇专题的真实前置关系，包含 Java 预备课；已读不等于掌握。

- `/knowledge`：依赖图、状态筛选、节点聚焦、课程跳转与可访问列表。
- `/execution`：递归与反转链表的受限教学推演，展示逐行高亮、调用帧、作用域、堆对象和引用；不执行任意 Java。
- `/compare`：相同输入下同步展示栈/队列、BFS/DFS、归并/快排；教学步骤不代表耗时测量。
- `/complexity`：循环、递归、额外缓冲区和输出规模的时间/空间分析。
- 章末保留原题与登记规则，每章补齐 Easy/Medium，并给出前置知识与本地手算题。

## 自适应与错题

`learning-insights.js` 根据最近 12 次有效答题的正确率、耗时和难度提供启发式推荐，不足 4 次从起步开始；用户可关闭。它不是能力诊断或 AI 评分。`learning.attempts` 最多保存 600 条，包含题目签名、分类与耗时，复用现有存档清洗、合并与同步。概念、边界、复杂度错误率在复习页展示，格式无效的答案不计入。

## Java 运行

电脑端按需加载 Monaco，隔离 iframe 内的 CheerpJ worker 编译执行 Java。首次运行需确认流量提醒，加载显示真实阶段与不定进度条；无法取得下载总字节数时不伪造百分比。流量为估计，缓存、类库和运行器版本会改变实际大小。

760px 及以下或粗指针设备只读高亮，不提供运行/编译入口。界面和运行器同时检查设备，运行中切到阅读设备会停止。移动端仍可完成填空、排序、选择与手算。

## 存档与免登录迁移

默认游客学习。JSON 导入提供预览与合并；账号同步可选，使用 Supabase Auth/RLS。加密数据串使用 Web Crypto、PBKDF2-SHA256（210000 次）和 AES-256-GCM，每次生成随机盐和 IV，密文使用 Base64 编码。Base64 本身不是加密。

数据不上传服务器，口令和内容分开传递。24 小时到期时间参与认证并由本地时钟校验；离线方案无法撤回已复制内容，也无法防止持有口令者修改时钟或自行解密。解密后仍需备份校验与预览确认，账号切换清空传输内容。

## 搜索与设计

全文索引覆盖课程正文、专题、代码和注释、任务及当前存档私人笔记。Fuse.js 对较长查询提供保守错字匹配，精确结果优先；短查询保持精确匹配。笔记不发送到搜索服务。

学习进度、通过比例和复习记录替代 XP 与等级。主题保存在本设备，不进入客流统计。版本变化统一记录在 `CHANGELOG.md`。
