## 教学上的取舍

采用“生活问题 → 具体例子与图中状态 → 正式概念 → 操作条件 → 自检与变式 → Java”的顺序。新内容单独分成专题，避免让基础章节继续无节制变长。原课程每节新增的是该节具体的边界与推理，不替换已经对应的图示或悄悄改动案例输入。

进阶内容先建立能手算、能说清条件的理解。Manacher、Tarjan/Kosaraju、复杂背包等篇是概念与推理入门；没有在线代码题的篇目明确说明这一点，未声称完成了相应专家级训练。Java 后端与算法工程师职业路线继续独立，算法专题也不替代机器学习的数学、Python 和工程训练。

### 真实可修改的推演

前缀和、定长窗口和、选择排序、计数排序、单调栈、单调队列、最大连续子数组、树状数组。每次应用输入重新生成步骤，历史帧保留独立快照；非法输入不覆盖最后一份有效实验。

### 新增 Java 任务

选择排序、小值域计数排序、BigInteger 精确加法、右侧第一个更大值、窗口最大值、并查集组数、离散化、树状数组更新与前缀查询、字典树前缀计数、最大连续子数组和、无限硬币最少数量、拓扑可完成性。每题 5 组数据，覆盖最小输入、重复值、负值或不可达等适用边界。判题运行实际程序结果，不以源代码字符串匹配冒充算法验证。

## 参考与校正

主要路线：[英雄编程 · 数据结构和算法学习路线](https://ufbva3m5zn.feishu.cn/docx/BYlOdtTPSoIdRqxFIeec5vBznug)。参考其四阶段分类与知识点覆盖，讲解、输入、推演和练习由本站重新编排。

另外核对了 [Princeton Algorithms](https://algs4.cs.princeton.edu/)、[Java 17 PriorityQueue 文档](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/util/PriorityQueue.html) 及 [CP-Algorithms](https://cp-algorithms.com/) 中有关堆、最短路、并查集、树状数组、字符串哈希和强连通分量的说明，各篇保留相关深入资料入口。

特别区分：递归调用树与实际树节点；普通树搜索与 BST 搜索；堆顶读取/删除/建堆的不同成本；BFS 队列与分层；快速排序期望与最坏时间；计数重建版与稳定排序版；SPFA 最坏情况；最大匹配与稳定婚配；哈希相同与真正相等；不同背包的可选次数与循环方向。
