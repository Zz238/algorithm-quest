## 工程与界面

| 建议 | 分支状态与验证入口 |
| --- | --- |
| 非法路由与损坏存档 | 非数字、超范围、缺参数及未知子路径显示 404。无法解析和无法写入分别提示；保留损坏原文，保护失败时不覆盖。旧打卡链接仍重定向到账号页。 |
| 拆分应用与课程数据 | 页面从 App 拆出，导航、进度、云同步各自独立。移除旧课文与内嵌代码对象的重复副本。章末实验有明确模式与输入字段映射，未知实验类型报错。 |
| 本机写入和多标签页 | 大存档批量写入，离页、切换账号和开始同步前保存。草稿按账号与题目隔离。游客替换有本机代次，避免旧标签页把数据合并回来。 |
| 代码阅读与键盘 | 整个代码区只有一个行号进入 Tab 顺序，方向键切换解释；术语选择、自动换行、全屏和复制降级。 |
| 静态检查和测试分层 | ESLint、Prettier、数据结构与状态回归、Vitest 组件测试及 Playwright 浏览器用例。所有随机参考检查固定种子。CI 同时检查内容、构建、七种视口和离线版。 |
| 只读验证与离线构建 | Java 验证只写临时目录；生成样例独立运行。离线构建验证 JS、CSS 和图标已内联，图解 SVG 没有外部依赖。 |
| 导航、触控、对比和字体 | 保留当前蓝白视觉及导航下划线；首屏紧凑，提示下一课；正文与代码分别使用无衬线和等宽字体。加强输入和答题边界，移动端主要学习按钮至少 44px。 |
| 长页与可访问性 | 章节栏及桌面页内目录固定；章末题有题目、练习与提示、题解和完成锚点。提供跳到正文、页面标题、主标题焦点、移动端术语内联详情和键盘可操作的导入控件。自动播放时暂停读屏播报。 |
| 实测性能 | 同一环境用原版与分支构建对照。移除重复课程数据后，JS 传输体积（gzip）下降约 10 KB，即使加入图解、搜索和备份。保留单文件构建，不为这点差异增加拆包复杂度。 |

建议的人工验收路线：数组第 2 节看 a[i+1]，链表第 3 节看新节点的两条连接，归并第 3 节观察写回，学习记录中试导入预览。使用正式账号的真实跨设备同步与实际零基础用户试学仍需在对应环境验收。
