本轮已准备任务与记录表，尚未招募或完成真实参与者试学。自动测试通过不代表真人已经理解课程。

## 对象与安排

邀请约 5 位没有 Java 编程和算法经验的志愿者。用 A–E 代号记录即可，不需要姓名、IP、私人笔记或账号信息。每人约 20 分钟，先说明是在测试课程是否易懂；卡住时可以直说或停止。

- 0–3 分钟：从首页找到适合自己的起点，说出之后会学什么。
- 3–8 分钟：学习第 4 章下标小实验；给出 `a=[4,8,6]`、`i=0`，问 `a[i+1]` 是多少，`i` 是否改变；再令 `i=2`，问能不能读取。
- 8–13 分钟：学习第 6 章对象与引用；给出 `a=[1,2]`、`b=a`、`b[0]=9`，问对象有几份、从 a 读到什么；再问 `b=null` 会不会清空数组。
- 13–18 分钟：学习第 3 章 for 循环；给出 `[2,4,1]`、`sum=0`，让参与者手动写出每轮总额 `2、6、7`，并解释何时执行 `i++`。
- 18–20 分钟：尝试“记下这一步”、收起笔记、回首页继续学习；询问最难理解的一句和最有帮助的一幅图。

先听参与者解释，不要立刻提示标准答案。需要帮助时记录帮助出现的位置；给出提示后再换一组数据，避免把跟着答案重复当成掌握。
